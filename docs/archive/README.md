# Archived project records

These records preserve what was discussed or measured on a particular date.
They may contain superseded hardware status, transport choices, commands and
next steps. Use the [repository introduction](../../README.md),
[current architecture](../architecture/ROS_ARCHITECTURE.md) and
[feature status](../project/FEATURE_STATUS.md) for the active project.

| Record | Purpose |
| --- | --- |

| [Commissioning: 11 October 2026](COMMISSIONING_2026-10-11.md) | Pi software/camera versions, service and transport measurements, PC inference/detection evidence |

Keep dated measurements intact. Record new commissioning results separately and
link their evidence from the current feature checklist; avoid appending history
into the active installation procedure.
